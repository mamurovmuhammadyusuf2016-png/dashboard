# Личный дашборд

Один экран про всю жизнь: соцсети (Instagram в первую очередь), деньги, привычки, заметки.
Этот файл — план проекта и список того, что нужно от владельца, чтобы всё заработало.

## 1. Модули

### 1.1 Instagram (главный модуль)

Источник данных: официальный **Instagram API with Instagram Login** (Meta).
Работает для Professional-аккаунта (Creator или Business), Facebook Page не нужна.
Дашборд раз в час/день забирает статистику и сохраняет снимки в свою базу,
поэтому история копится бесконечно (сам Instagram отдаёт ограниченный период).

Что показываем:

- **KPI-карточки**: подписчики (+/- за день, неделю, месяц), просмотры, охват,
  посещения профиля, взаимодействия, вовлечённые аккаунты. Каждая с сравнением к прошлому периоду.
- **Доля просмотров**:
  - от подписчиков vs не от подписчиков (в %, и динамика по дням);
  - по типу контента: Reels / посты / сторис / прямые эфиры;
  - доля просмотров с рекламы (если есть промо).
- **Графики по дням**: просмотры, охват, подписки/отписки, посещения профиля.
  Переключатель периода 7 / 30 / 90 дней / год, наложение «эта неделя vs прошлая».
- **Топ контента**: таблица постов и Reels с просмотрами, охватом, лайками, комментами,
  сохранениями, репостами, ER, средним временем просмотра Reels, подписками с поста.
  Сортировка по любой колонке, фильтр по типу.
- **Аудитория**: страны, города, возраст, пол; тепловая карта «когда подписчики онлайн»
  по часам и дням недели → подсказка лучшего времени публикации.
- **Сторис**: охват, ответы, переходы вперёд/назад, выходы.
- **Цели**: «10 000 подписчиков к 1 января» с прогнозом по текущему темпу.
- **Алерты**: пост «залетел» (просмотры выше среднего в N раз), охват просел, отписки выросли.
- **Конкуренты**: публичные метрики других бизнес-аккаунтов по username
  (подписчики, среднее по лайкам/комментам).
- **Хэштеги и подписи**: какие хэштеги/длина подписи коррелируют с просмотрами.
- Еженедельный дайджест в Telegram.

Запасной вариант, если API пока не подключён: ручной ввод цифр из встроенной статистики
Instagram (быстрая форма) — дашборд тот же, источник другой.

### 1.2 Другие соцсети (по выбору)

- **Telegram-канал**: подписчики, просмотры постов, ER (через Bot API или TGStat).
- **YouTube**: просмотры, время просмотра, подписчики, доход (YouTube Analytics API).
- **TikTok**: просмотры, лайки, подписчики (Display API; статистика ограничена).
- **Threads**: просмотры, лайки, репосты (Threads API с инсайтами).
- **X / VK / Facebook / LinkedIn**: по запросу.
- Сводная карточка «вся аудитория»: суммарные подписчики и просмотры по всем площадкам.

### 1.3 Деньги

- **Быстрый ввод** трат и доходов: форма на 3 поля, работает с телефона.
- **Telegram-бот**: пишешь `-45000 такси` или `+2 000 000 реклама` — запись появляется в базе.
- **Категории и теги**, мультивалютность (UZS / USD / RUB и т.д.) с авто-курсом.
- **Графики**: доходы vs расходы по месяцам, доли категорий, тренд, норма сбережений.
- **Бюджеты** на категорию с прогресс-барами и предупреждениями.
- **Подписки и регулярные платежи**: список, дата следующего списания, сумма в месяц.
- **Источники дохода**: реклама в Instagram, коллаборации, работа, фриланс.
  Рекламные интеграции привязываются к посту → видно, сколько заработал каждый пост.
- **Цели-копилки**, долги/кредиты, общий капитал (наличные, карты, крипта).
- **Импорт из банка**: CSV/Excel выписка → автоматическая категоризация.
- Фото чека → распознавание суммы и магазина (AI).

### 1.4 Жизнь

- **Блокнот**: заметки в Markdown, папки и теги, поиск, закреплённые, быстрый захват идей.
  Отдельный список «идеи для Reels» со статусом (идея → снято → опубликовано → ссылка на пост).
- **Задачи**: список дел на сегодня, канбан, контент-план в календаре.
- **Привычки** со стриками и тепловой картой на год (спорт, чтение, вода, без сахара).
- **Здоровье**: сон, вес, шаги (импорт из Apple Health / Google Fit), тренировки.
- **Настроение**: оценка дня 1–5 + короткая запись, «год в пикселях».
- **Цели на год** с прогрессом.
- **Календарь**: Google Calendar, дни рождения, обратные отсчёты до событий.
- **Списки**: книги, фильмы, курсы.
- **Помодоро** и учёт времени по проектам.
- Виджеты: погода, курс валют, цитата дня.
- **Главный экран «Сегодня»**: сколько потратил, просмотры за вчера, привычки, задачи, заметка дня.
- **AI-ассистент**: «как прошла моя неделя?» — краткий отчёт по всем модулям.
- Глобальный поиск по всему.

## 2. Технологии (предлагаемый стек)

- Next.js + TypeScript, Tailwind, shadcn/ui, Recharts.
- База: Postgres (Supabase или Neon, бесплатный тариф) через Drizzle.
- Синхронизация соцсетей: cron-задача раз в час (Vercel Cron или GitHub Actions).
- Вход: один пароль владельца (или passkey).
- Хостинг: Vercel (бесплатно) или Docker на своём VPS.
- PWA: ставится на телефон как приложение, тёмная тема.
- Telegram-бот для быстрого ввода и дайджестов.
- Секреты (токены Instagram, ключи) — только в переменных окружения, не в репозитории.

## 3. Что нужно от владельца

### Instagram (обязательно)

1. Аккаунт должен быть **профессиональным** (Creator или Business).
   Переключается бесплатно: Настройки → Тип аккаунта и инструменты → Переключиться на профессиональный.
2. Username аккаунта.
3. Создать приложение на developers.facebook.com (я дам пошаговую инструкцию),
   добавить продукт «Instagram», сгенерировать токен доступа для своего аккаунта.
   Нужны разрешения `instagram_business_basic` и `instagram_business_manage_insights`.
   Токен долгоживущий (60 дней), дашборд будет продлевать его сам.
4. Положить App ID, App Secret и токен в переменные окружения на хостинге.
   В чат и в репозиторий их не вставлять.
5. Пока API не подключён: можно начать с ручного ввода цифр или скриншотов статистики.

Ограничения Meta: часть метрик недоступна, если меньше 100 подписчиков;
аудиторные метрики (страны, возраст) требуют 100+ подписчиков.
