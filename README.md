# Мой дашборд

Личный дашборд «всё о моей жизни»: финансы, фото, заметки, привычки, настроение, цели, здоровье (шаги, вес, сон), вишлист и обратные отсчёты. Русский интерфейс, тёмная и светлая тема, работает на планшете, в браузере телефона и как Android-приложение.

## Что внутри

- **Сегодня** — потрачено за день и месяц, доходы, остаток, привычки на сегодня, настроение, шаги и вес, «в этот день N лет назад» из фото, ближайшие события, закреплённые заметки.
- **Финансы** — быстрый ввод, категории с иконками и цветами, месячные бюджеты с прогрессом, графики: доходы/расходы за 6 месяцев, доли категорий, расходы по дням. Поиск и фильтры по операциям.
- **Фото** — загрузка с телефона или перетаскиванием, дата из EXIF, альбомы, избранное, просмотр на весь экран, скачивание. Хранятся только на устройстве.
- **Заметки** — теги, поиск, закреплённые.
- **Привычки** — отметки за неделю, серии, тепловая карта за год.
- **Настроение** — оценка дня и «год в пикселях».
- **Цели и копилки** — прогресс, темп пополнений и прогноз даты достижения.
- **Здоровье** — шаги (из телефона через Health Connect в Android-приложении, вручную или импортом CSV), вес с целью, сон.
- **Вишлист** — приоритеты, ссылки; «Купил» создаёт расход в финансах.
- **События** — дни рождения (с возрастом), ежегодные и разовые отсчёты.
- **Календарь** — месяц целиком: свои события, события из календаря телефона, траты, настроение, привычки и фото по дням. В Android-приложении читает Samsung Calendar и Google Calendar напрямую (через общий календарь Android), в браузере принимает файлы .ics.
- **Настройки** — имя, валюта (UZS по умолчанию), тема, цели, резервная копия (с фото или без), восстановление, демо-данные.

## Где хранятся данные

Всё хранится локально в браузере (IndexedDB) или внутри Android-приложения. Никакого сервера и аккаунтов. Между устройствами данные не синхронизируются: перенести можно через «Настройки → Резервная копия» и «Восстановить из файла». Если понадобится синхронизация, следующим шагом можно подключить бесплатную базу (Supabase) — код готов к этому.

## Шаги из телефона

Android-приложение читает шаги из **Health Connect**, куда пишут Samsung Health, Google Fit, Mi Fitness и большинство шагомеров. На Android 14+ Health Connect встроен, на более старых версиях ставится из Play Store. В разделе «Здоровье» нажми «Подключить» и разреши чтение шагов (и истории). Дальше шаги подтягиваются сами при открытии приложения.

В браузере шаги вводятся вручную или импортом CSV, который экспортирует приложение-шагомер.

## Календарь телефона

Samsung Calendar хранит события в общем календаре Android, поэтому Android-приложение читает их напрямую: «Календарь → Подключить» и разрешить доступ. Подтягиваются события за 6 месяцев назад и 12 вперёд, обновляются при каждом открытии приложения. В браузере можно импортировать .ics-файл (Samsung Calendar и Google Calendar умеют экспортировать).

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
npm run typecheck
```

Стек: Vite, React, TypeScript, Tailwind CSS v4, Dexie (IndexedDB), Recharts, vite-plugin-pwa, Capacitor 8 + @capgo/capacitor-health.

### Android

```bash
NATIVE=1 npm run build
npx cap sync android
cd android && ./gradlew assembleRelease
```

APK подписывается ключом из `android/keystore/dashboard.jks` (пароль `dashboard`), чтобы каждая новая сборка ставилась поверх старой без переустановки. Ключ лежит в репозитории, поэтому для публикации в Play Store его нужно заменить: положи свой keystore в секреты `ANDROID_KEYSTORE_B64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`, и сборка возьмёт его автоматически.

### Установка на телефон

1. Открой ссылку на APK на телефоне и скачай файл.
2. Разреши установку из этого источника, когда телефон спросит.
3. При обновлении просто установи новый APK поверх — данные сохранятся.

Как Telegram Mini App: в @BotFather для своего бота выбери *Bot Settings → Menu Button* и укажи адрес веб-версии. Откроется тот же дашборд внутри Telegram.
